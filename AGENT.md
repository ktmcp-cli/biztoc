# BizToc CLI - Agent Instructions

This is the BizToc CLI, part of the KTMCP project.

## What This CLI Does
- Fetch latest business news articles
- Filter by source or tag
- Output in human-readable or JSON format

## Authentication
Optional API key (some endpoints work without it).

## Common Commands
- `biztoc news` - Get latest business news
- `biztoc news --limit 50` - Get more articles
- `biztoc news --json` - JSON output
